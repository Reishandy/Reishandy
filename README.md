# Reishandy

**Software developer building native Apple apps, the backend services behind them and the servers they run on.**

I'm Muhammad Akbar Reishandy, a developer from Indonesia. Right now I'm a Junior Developer at Apple Developer Academy @ BINUS, building SwiftUI apps with a small team. Three of them are on the App Store, and I led the technical side on four. Before that I interned at Telkom Indonesia, where I built internal web apps with Laravel and React.

Outside of work I run a homelab: an Arch Linux box (yes, I use Arch btw) with about ten Docker services behind Nginx and Cloudflare Tunnel. Most of my own projects end up hosted there. Tech is a hobby for me as much as a job, so this profile has a bit of everything.

### What I work with

Mostly Swift and SwiftUI on the Apple side. For backends I use Python with FastAPI, PHP with Laravel, or Go, and on the web I add React and Tailwind. My databases are usually PostgreSQL, MySQL, MongoDB or SQLite. I've also done some Android work in Kotlin and Jetpack Compose. Everything gets deployed with Docker, Nginx and GitHub Actions on Linux.
